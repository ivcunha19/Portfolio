# Portfólio

Este projeto é um portfólio tech desenvolvido para apresentar minha trajetória na programação, reunindo informações sobre mim, projetos práticos e experiências relevantes. O objetivo é compartilhar um pouco de quem sou como desenvolvedor e como posso agregar valor a novos desafios e equipes.

### Tenologias utilizadas

ReactJS
TailwindCSS
HTML
CSS
JS
i18next
ThreeJS
React Three Fiber

### Instruções de uso e desenvolvimento

Após obter o código-fonte do projeto, abra um terminal na pasta principal.

Instale as dependências:

npm install

Após a instalação, execute o projeto em ambiente de desenvolvimento:

npm run dev

O terminal apresentará o endereço local da aplicação, normalmente semelhante a:

http://localhost:5173

Acesse esse endereço pelo navegador para visualizar o site.
